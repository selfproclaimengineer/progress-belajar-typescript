# Setup Repo + JS Topik 1–3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Siapkan repo `progress-belajar-typescript`, template PDF Typst bergaya Database CE 613, dan materi JS-1 sampai JS-3 agar Dion bisa mulai belajar hari ini (Minggu, 2026-11-01).

**Architecture:** Repo git berisi satu template Typst bersama (`template/praktikum.typ`) yang diimpor oleh setiap HO dan Soal. Tiap topik punya folder `HO/`, `Soal/`, `Jawaban/`, `Diskusi/`. Soal berisi file starter `data.js` yang bisa dijalankan; kunci jawaban asisten disimpan di luar repo dan dipakai hanya untuk memverifikasi Contoh Output.

**Tech Stack:** Typst (PDF), Node 24 (ESM), git, GitHub (repo private).

**Spec:** `docs/design.md`

## Global Constraints

- Bahasa HO dan soal: Indonesia; istilah teknis tetap Inggris.
- Tampilan PDF: halaman putih, satu font untuk semua teks termasuk kode, teks minimal 12pt, satu palet triadic tenang dengan peran tetap (struktur, Catatan, Perhatian).
- Header "Praktikum JavaScript & TypeScript", footer nomor halaman.
- HO 5–8 halaman: Tujuan Praktikum, Dasar Teori dengan "Listing n", kotak Catatan/Perhatian, Coba Sendiri.
- Soal: Beginner (0.3), Intermediate (0.3), Advanced (0.4); 10–14 butir; jenis butir mencakup tulis fungsi + Contoh Output, "kode temanmu salah", "mengapa", "tulis ulang dengan cara lain".
- Domain kasus: kasir supermarket, dompet/bank, sistem rumah sakit, marketplace.
- Setiap topik bisa diselesaikan Dion dalam 1,5–3 jam.
- Kunci jawaban asisten tidak pernah masuk repo.
- Dependency: tidak ada untuk topik JS.

## Review Focus

- Contoh Output di soal tidak cocok dengan hasil kode yang benar: setiap butir yang punya Contoh Output diverifikasi dengan kunci jawaban di scratchpad.
- File starter gagal dijalankan (`node data.js` error, ESM vs CommonJS): setiap starter dijalankan sebelum commit.
- PDF gagal compile atau font fallback ke font lain: compile dengan `typst compile` dan cek tidak ada warning font.
- Soal "kode temanmu salah" ternyata error, bukan salah diam-diam: jalankan kode itu dan pastikan berjalan tanpa error tetapi hasilnya salah.
- Butir soal bisa diselesaikan dengan sintaks yang belum diajarkan di HO topik itu atau sebelumnya: cek manual per butir.
